## HR Analytics Dashboard Tableau

## 📌 Project Overview

The HR Analytics Dashboard is an interactive Tableau dashboard designed to analyze employee demographics, attrition, job satisfaction, education, age distribution, and workforce characteristics.

The dashboard transforms HR data into meaningful visual insights that can help organizations understand employee attrition patterns and workforce trends.


## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall employee workforce composition
- Understand employee attrition patterns
- Analyze attrition by department and gender
- Study employee distribution across different age groups
- Analyze attrition across education fields
- Understand job satisfaction across different job roles
- Compare attrition rates across gender and age groups
- Create an interactive HR analytics dashboard using Tableau
